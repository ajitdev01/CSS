## 📖 About This Repository

This repository documents a practical, hands-on journey through **Cascading Style Sheets (CSS)** — progressing systematically from core styling fundamentals to modern responsive layouts and interactive animations.

### 🌟 Key Highlights

- 🟢 **Progressive Difficulty**: Step-by-step curriculum starting with element displays up to keyframe animations.
- 🧩 **Practice-Driven**: Every core concept is accompanied by dedicated practice sets (`Practice Sets 3–8`).
- 📱 **Modern Layout Techniques**: In-depth exploration of Flexbox, Media Queries, and Mobile-First responsive design.
- 🚀 **Real-World Capstone**: Hands-on integration of all learned concepts into a complete CSS project.

## ▶️ How to Run

Because this repository uses native HTML5 and CSS3, no build steps, Node packages, or external dependencies are required.

### Option 1 — Direct Browser (Simplest)
1. Navigate to any folder (e.g., [`Level-1/`](./Level-1/)).
2. Double-click any `.html` file (e.g., `display.html`).
3. The page will immediately open in your default browser.

### Option 2 — VS Code Live Server (Recommended)
1. Open this repository folder in **Visual Studio Code**.
2. Install the **Live Server** extension (`ritwickdey.LiveServer`) if not already installed.
3. Right-click any `.html` file and select **"Open with Live Server"**.
4. Enjoy hot-reloading as you edit and experiment with CSS properties!

### Option 3 — Python Local Server
Run a local HTTP web server using Python from your terminal:

```bash
python3 -m http.server 8000
```

Then navigate to `http://localhost:8000` in your web browser.

## 🧠 Learning Approach

This repository adheres to a practical, iteration-focused learning framework:

```text
Learn Concept  ──>  Write Code  ──>  Practice Set  ──>  Experiment  ──>  Build Project
```

1. 📚 **Learn**: Study fundamental property specifications and mechanics.
2. 💻 **Code**: Hands-on implementation of standalone concepts.
3. 🧩 **Practice**: Solve targeted problem sets in `Practice Sets 3–8`.
4. 🔬 **Experiment**: Modify values, test edge cases, and inspect layout behavior in browser DevTools.
5. 🚀 **Build**: Synthesize knowledge by creating complete project UIs.
